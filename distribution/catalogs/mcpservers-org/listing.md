# mcpservers.org free submission

Open [Submit Your MCP Server](https://mcpservers.org/submit). Select the Free
plan. A paid review option is separate and is not needed for this draft.

| Form field | Value |
| --- | --- |
| Server Name | VPSnet |
| Category | Cloud / DevOps, choosing the closest available category |
| Short Description | Manage VPSnet servers, applications, DNS, private networks and Functions with customer-selected services and OAuth permissions. |
| Repository, Website or Documentation | https://github.com/bacarrdy/vpsnet-mcp |
| Official MCP Registry Name | `com.vpsnet/vpsnet`, after its record is published |
| Supports remote connections | Yes |
| Contact Email | Publisher supplies an actual organizational contact address in the form |
| Submission plan | Free |

If the form exposes remote setup fields, use `https://mcp.vpsnet.com/mcp`,
Streamable HTTP and OAuth; no API key or secret belongs in a public field.
Save the real submission receipt and check the final listing after review.

Source: [Provider's submission form](https://mcpservers.org/submit).
