# PulseMCP listing record

First publish `com.vpsnet/vpsnet` in the official MCP Registry, then search
[PulseMCP servers](https://www.pulsemcp.com/servers) for that exact name and
`https://mcp.vpsnet.com/mcp` to avoid duplicates. PulseMCP's own API documentation
lists official-registry data and manual submissions among its sources.

The site links [Submit server/client](https://www.pulsemcp.com/submit), but this
form could not be verified during preparation. Treat its availability as
unconfirmed; do not claim a manual submission was accepted or that indexing
will happen automatically within a particular time.

If the publisher's live form accepts submissions, use:

- Name: VPSnet
- Repository: https://github.com/bacarrdy/vpsnet-mcp
- Website: https://www.vpsnet.com
- Registry name: `com.vpsnet/vpsnet`
- Hosted endpoint: https://mcp.vpsnet.com/mcp
- Transport: Streamable HTTP
- Authentication: Customer OAuth with selected services and permissions
- Description: Manage VPSnet servers, applications, DNS, private networks and
  Functions with authorized customer access. Diagnose Linux VMs and perform
  permitted file or command operations on selected services.
- Pricing statement: A VPSnet account is required; underlying services have
  their own prices. Do not label the infrastructure free.

Supply the organization's actual contact address only in the private form.
If manual intake is paused, retain this record and use the official-registry
route; verify whether PulseMCP has indexed it before reporting completion.

Sources: [PulseMCP API data sources](https://www.pulsemcp.com/api),
[PulseMCP submission entry](https://www.pulsemcp.com/submit).
