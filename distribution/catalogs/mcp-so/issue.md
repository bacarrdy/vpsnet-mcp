Title: Add VPSnet remote MCP connector

Name: VPSnet

Repository: https://github.com/bacarrdy/vpsnet-mcp

Website: https://www.vpsnet.com

Remote endpoint: https://mcp.vpsnet.com/mcp

Description: Manage VPSnet servers, applications, DNS, private networks and
Functions with customer-selected services and OAuth permissions.

Features: Inspect existing services and application state, diagnose Linux VMs,
and perform permitted DNS, networking, file and command operations. Tools are
limited by the customer's grant. The hosted directory profile excludes
purchases, billing and account API-key management.

Connection: Streamable HTTP with customer OAuth, PKCE and dynamic client
registration. Setup: https://github.com/bacarrdy/vpsnet-mcp/blob/main/llms-install.md
