# GitHub MCP Registry nomination

The GitHub guide directs publishers to publish in the official MCP Registry,
then nominate the server to `partnerships@github.com`. Prepare the message below
after verifying the live record. Sending it is a separate publisher action.

Subject: VPSnet MCP Registry inclusion request

Hello GitHub MCP Registry team,

Please consider VPSnet for inclusion in the GitHub MCP Registry.

- Name: VPSnet
- Official MCP Registry name: `com.vpsnet/vpsnet`
- Repository: https://github.com/bacarrdy/vpsnet-mcp
- Website: https://www.vpsnet.com
- Remote endpoint: https://mcp.vpsnet.com/mcp
- Transport: Streamable HTTP
- Authentication: Customer OAuth with PKCE; services and permissions are
  selected during consent. Dynamic client registration is supported.
- License: MIT
- Description: Manage VPSnet servers, applications, DNS, private networks and
  Functions with authorized customer access. Diagnose Linux VMs and perform
  permitted file or command operations on selected services.
- Setup: https://github.com/bacarrdy/vpsnet-mcp/blob/main/llms-install.md
- Privacy: https://www.vpsnet.com/en/information/privacy-policy

The publisher should attach the exact released version and verified official
registry record link, plus any review evidence requested by GitHub.

Source: [GitHub publishing and nomination guide](https://github.blog/ai-and-ml/generative-ai/how-to-find-install-and-manage-mcp-servers-with-the-github-mcp-registry/).
Official registry publication and GitHub curation are separate steps.
